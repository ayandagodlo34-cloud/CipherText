# Caesar Cipher Tool

A Java EE web application that encrypts and decrypts text using the classic Caesar cipher. Every operation is logged to a Derby database with full history tracking.

## 📖 About

The Caesar cipher is one of the oldest and simplest encryption techniques. Each letter in the plaintext is shifted a fixed number of positions down the alphabet. This project wraps that algorithm in a modern Java EE web stack, demonstrating JPA persistence, EJB business logic, and servlet-based routing.
